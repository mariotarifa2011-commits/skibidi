# 🎵 Skibidi

Un proyecto web moderno e innovador con diseño atractivo y funcionalidades interactivas.

## 📋 Contenido

- **index.html** - Página principal con estructura completa
- **styles.css** - Estilos modernos con gradientes y animaciones
- **script.js** - Funcionalidades interactivas y comportamientos dinámicos

## 🎨 Características

✨ **Diseño Responsivo** - Se adapta a todos los dispositivos
🚀 **Rendimiento Optimizado** - Carga rápida y fluida
💫 **Animaciones Suaves** - Efectos visuales atractivos
🔗 **Navegación Fluida** - Desplazamiento suave entre secciones
📱 **Mobile First** - Optimizado para dispositivos móviles

## 🚀 Secciones

1. **Navegación Sticky** - Menú siempre visible mientras desplazas
2. **Hero Section** - Presentación principal con animaciones
3. **Características** - Grid responsivo con 4 características principales
4. **Galería** - Galería visual con efectos hover
5. **Contacto** - Formulario de contacto funcional
6. **Footer** - Pie de página con enlaces sociales

## 🎯 Tecnologías Utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Animaciones)
- JavaScript (Vanilla)

## 💻 Cómo Usar

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡Disfruta!

## 🎪 Personalización

Puedes personalizar fácilmente:
- **Colores**: Modifica las variables CSS en `styles.css`
- **Contenido**: Edita el HTML en `index.html`
- **Animaciones**: Ajusta los tiempos en CSS y JavaScript

## 📝 Variables CSS Disponibles

```css
--primary-color: #667eea
--secondary-color: #764ba2
--accent-color: #f5576c
--text-color: #333
--light-bg: #f8f9fa
--white: #ffffff
```
